8. Cookie и хранилище браузера

Сервис не использует cookie, счётчики аналитики и рекламы. В хранилище браузера на устройстве Пользователя сохраняется только необходимое для работы: данные входа, выбранный город и оформление, настройки экранов, копия страниц для работы без связи. Третьим лицам эти сведения не передаются; удалить их можно выходом из аккаунта или очисткой данных сайта в браузере. Если Сервис начнёт использовать аналитику, Оператор заранее изменит Политику и будет спрашивать согласие.

Оператор применяет: шифрование соединения (HTTPS, TLS 1.2 и выше); доступ к управлению Сервисом только у Оператора — по номеру телефона с кодом и отдельному паролю, с ограничением числа попыток; доступ к серверу только у Оператора — по ключу SSH, вход по паролю отключён; панель базы данных закрыта из интернета и открывается только через соединение с сервером по ключу SSH и по отдельному паролю; разграничение прав в базе; хранение кодов входа только в виде хэша с секретным ключом и их удаление после использования (не позднее суток); автоматическую блокировку адресов при попытках подбора доступа к серверу; ежедневное резервное копирование базы на сервере в РФ с еженедельной проверкой восстановления; круглосуточный автоматический контроль работы Сервиса; журналирование попыток входа и действий администратора.
